# 源码修复摘要 · 2026-11-12

本次更新发布源码与开发文档，不包含新的安装ZIP或7-Zip二进制。当前程序集版本仍为1.1.1；系统集成验收状态见[发布验收矩阵](RELEASE-VALIDATION.md)。

## 行为变更

- 安装只注册可选打开方式，不覆盖默认程序或清除UserChoice；用户主动勾选后才在成功安装时打开系统默认应用设置。
- 分卷入口规范化、去重并与普通包共同执行。传统ZIP从配套.zip进入；无法可靠确认分卷范围时保留源文件。
- 预览采用单工作任务和时间/规模上限，超限省略预览并保留操作；菜单编号和不可执行预览行遵守Shell契约。
- 引擎与部署使用跨进程文件租约；路径绑定元数据先保存再切换指针，保留旧引擎。
- 安装先后台准备和备份，再逐文件切换；支持文件回滚与中断恢复，注册状态单独报告。打包使用完整候选ZIP替换旧包。
- CLI统一退出码：0成功、1失败、2参数错误、3取消、4部分成功；新增非交互模式以避免脚本等待界面。
- 更新检查分离尝试/成功时间，失败15分钟至6小时退避，成功缓存24小时；缓存绑定引擎路径及版本。
- 禁用自定义下载URL，保留官方digest验证与本机离线引擎。官方下载大小上限仍是已知限制。
- 卸载报告文件删除失败；逐目录核验下载来源，保留本机、未知及冲突来源引擎。
- 配置共享同一模型和默认模板，保留注释、未知键和段落；明确空列表不恢复默认。
- 优化树构建，保留公开可变列表兼容；诊断原生资源作用域释放，菜单日志限制大小并轮转。
- 图标统一从现有ICO源导出，保持图像内容；固定开发依赖，支持只读资源一致性检查。
